# LOXNE — Миры под поверхностью

Локальное русскоязычное портфолио: монолит, четыре реальные работы, отдельные кейсы, управляемая разборка часов и оригинальный интерфейс Wordflow на учебных данных. Исходные приложения сохранены отдельно; портфолио использует проверенные экраны и необходимые ресурсы.

**Редакция от 2 ноября 2026:** главная заменена непрерывным пространственным путешествием. По новому уточняющему промпту текущая публичная итерация ограничена первым фрагментом: обнаружение машины → локальное влияние на стекло → раскрытие → проход внутрь → управляемые часы. Прокрутка управляет общей камерой; внутри доступны исходные 47 деталей и настоящий экран. Все четыре существующих кейса доступны через меню. FARO, Египет, Wordflow и финал имеют заготовки новой постановки, но не входят в этот фрагмент до визуальной приёмки пользователя. Local preview: **http://127.0.0.1:4316/**. Пользователь повторно выбрал «Обновить страницу без проверок и записи»; тесты, браузерная проверка, замеры и запись этой редакции не выполнялись. [acceptance.md](docs/qa/acceptance.md) относится к предыдущей версии. Публикация не выполнялась.

Новая главная: `src/components/JourneyCanvas.tsx`, `src/experience/journey/{architecture,exhibits,camera,reflection,chapters}.ts`, `src/pages/Home.tsx`, `src/styles/journey.css`. Граница первого фрагмента — `JOURNEY_LIMIT` в `chapters.ts`, ресурсы ограничены `createExhibits({openingOnly:true})`. На главной активен один renderer; прежний SceneHost используется только в кейсах. Локальный шоурил Remotion сохранён как материал предыдущей редакции и не подменяет новое интерактивное путешествие.

## Запуск

Команды выполняются из корня проекта. В Windows PowerShell используется `npm.cmd`, в других оболочках — `npm`. Версии зависимостей закреплены в `package-lock.json`; установка включает workspace `remotion/`.

```powershell
npm.cmd ci
npm.cmd run dev
```

Адрес разработки: **http://127.0.0.1:4310/**. Порт фиксирован; при занятом 4310 Vite завершится с ошибкой вместо перехода на другой порт.

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run check:assets
npm.cmd run build
npm.cmd run preview
```

Production preview также использует **http://127.0.0.1:4310/**; перед ним остановите dev-сервер. Он обслуживает результат `dist/`. Для хостинга маршрутов `/work/:id` и `/credits` нужен SPA fallback на `index.html`; деплой здесь не выполняется.

`check:assets` сравнивает подготовленные ресурсы с их источниками и запрещает исходные базы/профили/BLEND в `public/`. В текущем исследовательском workspace имеются `.research/chasi`, `.research/pizza`, `.research/egi`, `.research/EnCard` на зафиксированных commits. Повторная проверка копий BLEND и тесты оригинального Wordflow требуют этих исходников. Если переносится только продуктовая папка без `.research/`, источники нужно восстановить по [ASSET_SOURCES.md](ASSET_SOURCES.md); обычная сборка использует уже подготовленный `public/`.

Повторная подготовка ресурсов при наличии проверенных исходников:

```powershell
node scripts/prepare-assets.mjs
node scripts/prepare-wordflow-demo.mjs
node scripts/check-assets.mjs
```

Подготовка демо допускает только явно разрешённые файлы. Она не читает резервные базы и не подключает авторизацию.

## Видео

```powershell
npm.cmd run remotion:studio
npm.cmd run video:render
```

Studio: **http://localhost:4315/PortfolioShowreel**. Сначала следует просмотреть композицию и её стыки в Studio. Render настроен на 1920×1080, 30 FPS, 660 кадров / 22 секунды, H.264/yuv420p, без звука, с выводом в `public/assets/video/portfolio-showreel.mp4`. Общие подготовленные ресурсы подключены через `Config.setPublicDir('../public')`.

Команда render не означает, что итог уже просмотрен. MP4 и `public/assets/images/showreel-poster.jpg` уже присутствуют в public; эта документационная проверка установила наличие файлов, без просмотра или ffprobe. Статус фактического preview, параметров экспорта и итоговой приёмки ведёт владелец видео в [docs/qa/video.md](docs/qa/video.md). Remotion — отдельный workspace и не импортируется runtime сайта.

## Как устроено

React/TypeScript/Vite отвечают за HTML и маршруты, Three.js — за три сценических мира: монолит, часы и FARO. Один `SceneHost` управляет canvas, активной DOM-областью, загрузкой и освобождением ресурсов. Движение вычисляется из абсолютного progress.

Фактическая реализация использует нативную прокрутку и один **GSAP ticker** с dirty-rendering; отдельный ScrollTrigger или Lenis не подключены. Метрики HTML-глав находятся в `domStory.ts`, camera/pose — в модулях миров. Это уточнение исходного плана, а не второй скрытый animation loop.

Египет представлен настоящими экранами и исходным растровым порталом в DOM/CSS. Новый выдуманный 3D-храм не создавался; полный original runtime экспозиции не встроен. Wordflow представлен настоящими снимками и автономным исходным интерфейсом в iframe, а не новой имитацией карточек.

Предусмотрены и проверены статичные кадры при отказе 3D, уменьшение движения и ручной инспектор часов. Активный монолит измерен на текущем компьютере; физические телефоны и другие браузеры остаются за границами этой проверки.

## Wordflow и учебные данные

Встроенный адрес: `/demos/wordflow/index.html`. Демо сохраняет оригинальные стили, типографику, карточки, три ответа и управление словарями EnCard. Начальное состояние — шесть слов и одна коллекция, нормализованные оригинальной моделью. Двадцать встроенных слов исходника доступны в общем словаре.

Учебные ключи имеют префикс `loxne.wordflow.demo.v1:`. Кнопка «Начать заново» удаляет только этот namespace. Сообщение принимается лишь от parent на том же origin. Iframe сохраняет same-origin для этого контракта; это изоляция **данных демо**, а не утверждение о независимом security-origin. При запрете storage используется память вкладки с уведомлением.

Реальные профили, backups/SQLite, Telegram SDK, авторизация, Cloudflare D1 и облачные endpoints не переносились. CSP запрещает внешние подключения, включая внешнюю озвучку; системная речь зависит от браузера. Ссылка «Открыть в Telegram» ведёт к исходному личному приложению, но его вход и облачная синхронизация в этой проверке не использовались. Подробности: [Wordflow QA](docs/qa/wordflow-demo.md).

## Источники и проверки

GLB, фотографии экранов, шрифты, notices и commits перечислены в [ASSET_SOURCES.md](ASSET_SOURCES.md). Редактируемые Blender-файлы находятся в `assets/source/`, вне `public/`; монолит редактируется процедурным исходником. Pizza — Rigsters, CC BY 4.0: авторство, ссылка и описание прежних изменений сохранены.

Метод визуальной доводки — [Unslop](https://github.com/heydamir/unslop), **Damir Sokolovsky / [@heydamir](https://x.com/heydamir), CC BY 4.0**. Его направление и девять проходов применяются к новой оболочке; по просьбе пользователя оригинальный дизайн работ сохраняется. [Аудит](docs/qa/unslop.md) разделяет проверку кода и визуальный просмотр.

Автотесты поведения были написаны до продуктовой реализации; исходный RED сохранён в `docs/qa/tests-before-implementation.txt`. Актуальный результат следует получать командами выше; число тестов здесь намеренно не закреплено.

Подтверждено главным агентом в браузере на 2 ноября: Wordflow при ширине 390 px — переворот, «Знаю» → 1/6, отмена → 0/6, словари и внешний reset → 0/6; мобильное меню при 360×640 — открытие/закрытие по Escape. Это сценарии в desktop-браузере, не проверка реального телефона, Telegram или облака. Полный перечень, включая финальные сцены и переходы, находится в итоговом отчёте.

План проверок: [browser-acceptance.md](docs/qa/browser-acceptance.md). Фактические отчёты: [Wordflow](docs/qa/wordflow-demo.md), [Unslop](docs/qa/unslop.md), [видео](docs/qa/video.md). Непроверенные пункты этих документов не считаются завершёнными.

## Итоговая приёмка

Текущие результаты сведены в [acceptance.md](docs/qa/acceptance.md): 141 тест, TypeScript, asset verification и production build проходят. Проверены четыре кейса, история, быстрые переходы, пять циклов GPU-ресурсов, reduced-motion/error branches, шесть размеров окна и воспроизведение видео. Production preview для этой сессии работает на http://127.0.0.1:4316/; dev — на 4310.

Активный монолит: около 59.79 FPS в 30-секундном окне при 1440×900, DPR 1 на текущем компьютере. Это не измерение физического телефона. Предыдущие промежуточные замечания о шторке/материалах закрыты в итоговом отчёте. Для предотвращения повторных transmission targets один процедурный monolith живёт вместе с renderer; тяжёлые модели загружаются по активному миру и соседу.
