# Wordflow: подготовка встроенного демо и проверка ресурсов

Дата: 2 ноября 2026 года. Подготовка адаптера и файлов выполнена без запуска браузера этим исполнителем. Последующую проверку iframe проводит главный агент; подтверждённые результаты отделены ниже от Node-тестов.

## Что подготовлено

В `public/demos/wordflow/` находятся ровно шесть файлов: `index.html`, `demo-state.js` и четыре оригинальных модуля/стиля в `public/`. Источник — EnCard commit `43a41053321f6c96d7880c14bf353dd384380ced`.

Сохранены оригинальные встроенные стили, Manrope / DM Serif Display и их лицензионные уведомления, три кнопки ответа, карточки, модель обучения, управление словарями и импорт/экспорт. Четыре внешних UI-модуля скопированы побайтово.

Изменения оболочки:

- Удалён только необязательный inline-загрузчик Telegram SDK.
- В title добавлено «Локальное демо».
- Исходные inline-программы отложены через `type="text/wordflow-script"`; их обращения к `localStorage` направлены в `window.WordflowStorage`, как в оригинальном hosted `app/route.ts`.
- Модуль `demo-state.js` устанавливает storage adapter и запускает эти исходные программы по порядку. Он не переписывает карточки или алгоритм обучения.
- CSP запрещает внешние сетевые соединения; Telegram/backend/service worker не перенесены.

Демо создаёт одну коллекцию «Миры под поверхностью · демо» с шестью словами: surface, craft, motion, depth, light, explore. Начальное состояние проходит оригинальный `WordflowModel.normalizeDocument`; очередь активной коллекции — шесть слов, прогресс — 0 из 6, история пуста. Встроенные двадцать учебных слов сохраняются в общем словаре. Ни один реальный профиль или снимок БД не читался.

Состояние хранится под префиксом `loxne.wordflow.demo.v1:`. У старого исследовательского preview на порту 4314 другой namespace (`wordflow.preview.synthetic.v1:`), его данные не переносятся. Если browser storage запрещён, демо использует память вкладки и сообщает об отсутствии сохранения после закрытия.

## Встраивание и сброс

Iframe src: `/demos/wordflow/index.html`. URL при работающем основном Vite-сервере: `http://127.0.0.1:4310/demos/wordflow/index.html`.

Внешняя кнопка портфолио отправляет сообщение в iframe:

```js
iframe.contentWindow.postMessage({type: 'loxne-wordflow-reset'}, location.origin);
```

Обработчик принимает сообщение только если `event.origin === location.origin`, `event.source === parent` и тип точно равен `loxne-wordflow-reset`. Он удаляет только ключи своего namespace и перезагружает iframe. Настройки портфолио, обычные Wordflow-ключи и похожий prefix другой версии остаются нетронутыми. Для этого контракта iframe должен сохранять тот же origin; sandbox с opaque origin несовместим с намеренной проверкой origin.

## Границы демо

Это настоящий исходный UI с синтетическим локальным состоянием. Hosted-панель профиля, авторизация Telegram, Cloudflare D1 и облачная синхронизация отключены. Внешние аудиозаписи Wikimedia также недоступны из-за CSP; системная речь зависит от браузера и не проверялась. Записи о проверке исходного preview на 4314 не заменяют проверку этой новой встроенной сборки.

Известное поведение исходника сохранено: при отсутствии личных коллекций обзор переходит к общему словарю, а CSS скрывает создание первого словаря. Синтетическая существующая коллекция делает управление доступным для демонстрации. Удаление всех коллекций может вернуть это исходное состояние; внешняя кнопка сброса восстанавливает исходную демо-коллекцию.
