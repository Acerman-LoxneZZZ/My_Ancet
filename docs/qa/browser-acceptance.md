# Критерии проверки до реализации

Созданы до продуктового кода по просьбе пользователя. Автоматические тесты находятся в `tests/`; ниже — браузерные сценарии, которым нужны настоящий DOM, рендер и управление.

- Первый экран читается при загрузке модели и при отказе WebGL; остаются навигация, четыре работы и контакт. Есть статичный законченный резервный кадр.
- Скролл раскрывает монолит, входит в галерею и возвращает его в финале; обратный скролл возвращает ту же позу. «Сразу к работам» действительно обходит введение.
- Каждая работа содержит крупный реальный экран и исходный объект/карточки. Дизайн сверяется с `docs/design/review-v2/`.
- Любой кейс открывается напрямую, следующая работа и возврат действуют; при прямом входе возврат ведёт к соответствующей работе. Back/Forward и быстрые клики не оставляют шторку или блокировку.
- После перехода фокус доступен в содержании, клавиатура проходит меню и основные действия. Escape закрывает меню и просмотр видео.
- Часы: ползунок 0→100→0 возвращает исходную геометрию; выбор детали показывает её название. FARO: настоящее меню и корректная ссылка на исходник. Египет: реальная экспозиция и указание новой постановки. Wordflow: оригинальная карточка, три ответа, словари, прогресс, сброс только учебных данных.
- Проверить ширины 360,390,768,1440,1920, низкий экран и увеличение текста: нет горизонтального скролла, обрезанных действий и наложений. На телефоне интерфейс остаётся доступным без hover.
- При reduced motion нет пролёта/частиц, сохранённые кадры и HTML доступны. Переключение режима и resize сохраняют текущую главу.
- Проверить отсутствие лишних canvas; ошибки и поздняя загрузка не оставляют старые сцены. Скрытая вкладка не продолжает рендер. Пять циклов кейсов не накапливают GPU-ресурсы.
- Проверить шоурил в Studio и готовый MP4: все четыре работы, 22 секунды, 1920×1080,30FPS, корректные начало/стыки/финал, без обязательного звука.
- Итоговый production preview: главная, прямой кейс, 404, ресурсы; сборка не содержит `.research`, баз, `.blend` или Remotion runtime.

Этот список фиксирует ожидаемое поведение, а не объявляет проверки пройденными. Фактические результаты будут записаны отдельно.
