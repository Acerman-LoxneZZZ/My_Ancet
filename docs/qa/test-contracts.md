# Контракты начальных тестов

Дата: 2 ноября 2026 года. Тесты написаны до продуктовых модулей по прямому запросу пользователя. Этот документ описывает только `story.test.ts` и `scroll-memory.test.ts`, не статус всего проекта.

| Проверка | Файл | Связь с планом |
| --- | --- | --- |
| Clamp прогресса и безопасные неконечные значения | `tests/story.test.ts` | Задача 4: конечные абсолютные значения; пока без контракта поз камеры |
| Границы главы, обратный seek, нулевая высота | `tests/story.test.ts` | Задачи 4/9: независимое от направления вычисление прогресса |
| Resize сохраняет главу/локальный progress, не старые пиксели; round trip wide → narrow → wide | `tests/story.test.ts` | Задача 9: `resize_preserves_faro_progress`; этот контракт проверяется здесь вместо отдельного `scroll-layout.test.ts` |
| Отсутствующая глава/progress, новые границы документа, неизменность входных данных | `tests/story.test.ts` | Задача 9: восстановление и fallback |
| Разные history keys при одинаковом URL, обновление одной записи, defensive copy, clear | `tests/scroll-memory.test.ts` | Задача 8: корректные Back/Forward snapshots |
| Прямой вход во все четыре кейса; сохранённая позиция имеет приоритет, включая y=0 | `tests/scroll-memory.test.ts` | Задача 8 / Review Focus 1: возврат к экспонату без snapshot |

Числовая семантика: `clamp01` возвращает 0 для NaN и ±Infinity. `mapViewportChange` использует существующую главу и конечный progress, ограниченный диапазоном 0…1; иначе ограничивает сохранённый y диапазоном 0…maxY, неконечный y заменяет на 0. Для `getChapterProgress` нулевая высота должна дать конечное значение 0…1; точное ступенчатое поведение тестом не навязывается.

Запуск после подготовки владельцем package/runner:

```text
npm test -- --run tests/story.test.ts tests/scroll-memory.test.ts
```

Assertions ещё не выполнялись: это ожидаемый import-stage RED до реализации, не обнаруженный дефект существующего продукта. Успешный прогон здесь ещё не заявлен.

Стыки камеры, reduced motion, количество ScrollTrigger, быстрые переходы и реальные браузерные проверки остаются отдельными обязательными проверками следующих этапов.
