# LOXNE — сравнение исходных проектов и новой подачи

Это локальный дизайн-прототип для review, а не готовое портфолио. Слева показаны настоящие экраны четырёх запущенных исходных приложений, справа — предложенная презентация с сохранёнными интерфейсами и предметами. Часы и FARO используют оригинальные GLB; предметный свет, композиция и тарелка FARO добавлены для новой подачи. Сведения об источниках, атрибуциях и границах Wordflow-демо находятся в [SOURCES.md](./SOURCES.md).

Статичные снимки и файлы этой папки входят в Git. Просмотр сравнения не требует работающих серверов четырёх исходных приложений: экраны читаются из `assets/`. Однако JavaScript страницы импортирует Three.js, который пока берётся из установленной исследовательской копии `chasi`, а не поставляется внутри этой папки. Самостоятельного production runtime и корневого package.json у этого proof нет.

## Подготовка и запуск

Нужны Node.js 22.12+ и npm. Команды выполняются из корня репозитория портфолио.

Если `.research/chasi/` уже существует, повторно клонировать его не нужно. Для свежей рабочей копии сначала получить исходный проект и зафиксированную версию:

```powershell
git clone https://github.com/Acerman-LoxneZZZ/chasi .research/chasi
git -C .research/chasi checkout 9d214bcf2b5477550ba014c23881cecca32b802e
```

Установить зависимости исходного проекта по его lockfile и запустить сервер сравнения:

```powershell
npm --prefix .research/chasi ci --no-audit --no-fund
node docs/design/review-v2/serve.mjs
```

Открыть [http://127.0.0.1:4320/](http://127.0.0.1:4320/). Сервер доступен только на loopback и завершается по `Ctrl+C`. Он раздаёт эту папку, а `/vendor/three/` отображает на `.research/chasi/node_modules/three/`. Сборка не требуется. Если Three.js отсутствует, сервер сообщает команду установки и не запускается.

Если порт 4320 уже занят работающим предпросмотром, оставьте его работающим. Для отдельного просмотра можно выбрать другой порт:

```powershell
node docs/design/review-v2/serve.mjs 4329
```

В этом случае адрес — [http://127.0.0.1:4329/](http://127.0.0.1:4329/). Путь к файлам определяется относительно `serve.mjs`, поэтому после подготовки зависимостей сервер можно запускать и из другой текущей папки, указав путь к скрипту.

## Живые исходные приложения

Во время проверки четыре исходных UI были запущены и открыты по следующим адресам. Кнопка «Открыть проект» ведёт именно на живую локальную версию, поэтому требует соответствующего отдельного сервера:

| Проект | Локальный адрес | Статус/назначение |
| --- | --- | --- |
| «Ход времени» | [127.0.0.1:4311](http://127.0.0.1:4311/) | Исходное приложение `chasi`, разборка и осмотр модели |
| FARO | [127.0.0.1:4312/scene-3d/](http://127.0.0.1:4312/scene-3d/) | Исходный статический сайт пиццерии |
| Египет | [127.0.0.1:4313](http://127.0.0.1:4313/) | Исходная интерактивная экспозиция |
| Wordflow | [127.0.0.1:4314](http://127.0.0.1:4314/) | Автономный исходный UI с изолированными учебными данными; не проверка Telegram/D1 |

Сервер `serve.mjs` не запускает и не останавливает эти приложения. Например, часы можно отдельно поднять после `npm ci`:

```powershell
npm --prefix .research/chasi run dev -- --port 4311 --strictPort
```

Для остальных серверов использовать их исследовательские копии и описания в [SOURCES.md](./SOURCES.md). Для Wordflow существенны ограничения автономного адаптера: реальные профили, Telegram-вход и серверная синхронизация здесь не воспроизводятся. Остановка исходных серверов не меняет сохранённые снимки в сравнении.

## Проверка сервера

```powershell
node --check docs/design/review-v2/serve.mjs
```

HTTP-сервер поддерживает GET/HEAD, MIME для JavaScript, изображений, GLB, JSON и шрифтов; проверяет выход пути за разрешённую папку, включая symlink/junction. Это небольшой локальный сервер для review, не способ публикации сайта. Браузерная визуальная проверка и HTTP-проверка сервера — отдельные результаты.
