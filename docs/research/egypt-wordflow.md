## Египет: подтверждено кодом

- Статический HTML с семью главами: Нил, пирамиды, фараоны, письменность, боги, повседневная жизнь, наследие. Тексты и ссылки находятся в `index.html` и сохраняют смысл без WebGL.
- JavaScript / Vite, Three.js, GSAP + ScrollTrigger, Lenis. В `package.json`: Three `^0.183.0`, GSAP `^3.14.2`, Lenis `^1.3.26`, Vite `^7.3.1`. Это диапазоны исходного проекта, не рекомендация версий для нового портфолио.
- Портал представляет собой прозрачную растровую лицевую плоскость, заднюю плоскость панорамы и настоящие простые объёмные опоры/перемычку (`PlaneGeometry`, `BoxGeometry`). Это сценическая реконструкция с перспективной глубиной, а не детальная модель храма или фотограмметрия.
- Модель `sampleFlight(progress)` даёт абсолютное положение камеры и параметры затухания портала, света, резкости и песка. Обратная прокрутка не зависит от незавершённых tween-анимаций.
- Рендер, Lenis и ScrollTrigger связаны одним GSAP ticker. Реализованы ограничение DPR до 1.5, снижение DPR при медленных кадрах, остановка в скрытой вкладке, освобождение ресурсов, обработка потери WebGL.
- При ширине до 700 px либо `prefers-reduced-motion` исходная 3D-сцена не запускается. В портфолио мобильная постановка будет новой работой, поэтому нельзя приписывать её исходному сайту.
- Количество песчаных частиц: 360 при ширине более 900 px, иначе 160.
- По текущему README публичный домен не выбран. Кнопка «Открыть демо» для Египта пока не имеет подтверждённого публичного назначения.

Проверяемые исходники: [scene.js](https://github.com/Acerman-LoxneZZZ/egi/blob/1a4725dc9285a8d45ffead5f4342a3e3d94df92d/src/scene/scene.js), [flight.js](https://github.com/Acerman-LoxneZZZ/egi/blob/1a4725dc9285a8d45ffead5f4342a3e3d94df92d/src/experience/flight.js), [scroll.js](https://github.com/Acerman-LoxneZZZ/egi/blob/1a4725dc9285a8d45ffead5f4342a3e3d94df92d/src/experience/scroll.js), [main.js](https://github.com/Acerman-LoxneZZZ/egi/blob/1a4725dc9285a8d45ffead5f4342a3e3d94df92d/src/main.js).

## Wordflow: подтверждено кодом

- Реальный интерфейс — `index.html` с встроенными стилями, шрифтами и логикой, дополненный модулями `public/wordflow-*.js` и `public/profile-*.js`. React/Next/Vinext присутствуют в серверной оболочке, но неверно описывать всю пользовательскую часть как полностью написанную на React.
- Сервер: Vinext / Vite, Cloudflare Worker, D1, Drizzle schema. `app/route.ts` отдаёт HTML и запускает его только после выбора проверенного локального профиля.
- Карточки переворачиваются нажатием. Ответы «Знаю», «Не знаю», «Трудно» выполняются кнопками. Свайпы намеренно отключены; не демонстрировать свайпы как реальную возможность исходного проекта.
- Подтверждены личные словари, массовое добавление, поиск, повторение, редактирование/удаление собственных слов, подтверждение удаления, импорт/экспорт JSON, отмена ответа и статистика последних семи календарных дней.
- Стабильные ключи слов сохраняют идентичность при редактировании; изменение английского написания сбрасывает прогресс только соответствующего слова. История ограничена последними 5000 ответами за семь дней и общим размером документа 1 MiB.
- `server/telegram.mjs`: проверка Ed25519-подписи Telegram initData публичным ключом, срока до 24 часов, повторяющихся полей и ID бота. Токен бота для этой проверки не нужен.
- `server/profile.mjs`: авторизация каждого GET/PUT; данные связаны с проверенным владельцем. Атомарное условие `WHERE telegram_id = ? AND revision = ?` блокирует незаметную перезапись более новой версии (409 conflict).
- `public/profile-client.js` содержит отдельный кеш каждого профиля, локальные копии для восстановления, ручной выбор при конфликте, повторные попытки синхронизации и понятные статусы ошибок. `public/sw.js` кеширует оболочку для повторного запуска без сети. Первый вход и первичная загрузка требуют подключения; истёкший вход нельзя считать бессрочно действующим.
- Статистика в демо должна быть изолированной. Облачную синхронизацию в портфолио можно объяснить схемой или обозначенной симуляцией, не подключая реальные профили.

Ключевые источники: [profile.mjs](https://github.com/Acerman-LoxneZZZ/EnCard/blob/43a41053321f6c96d7880c14bf353dd384380ced/server/profile.mjs), [telegram.mjs](https://github.com/Acerman-LoxneZZZ/EnCard/blob/43a41053321f6c96d7880c14bf353dd384380ced/server/telegram.mjs), [profile-sync.js](https://github.com/Acerman-LoxneZZZ/EnCard/blob/43a41053321f6c96d7880c14bf353dd384380ced/public/profile-sync.js), [route.ts](https://github.com/Acerman-LoxneZZZ/EnCard/blob/43a41053321f6c96d7880c14bf353dd384380ced/app/route.ts).

### Публичный адрес

[Wordflow](https://wordflow-telegram.amirykaihan515bsu.chatgpt.site/) проверен обычным HTTP GET: статус 200, заголовок «Wordflow — английский по карточкам», HTML 2 284 422 байта. `/profile-client.js` также отдал 200 (28 689 байт), содержит ветку `if(!initData || !userId)` с сообщением «Откройте Wordflow в Telegram».

Следовательно, публичная оболочка доступна, но текущий опубликованный продукт не предоставляет обычному гостю полноценный вход в карточки без Telegram. Вход в Telegram и запросы к реальным профилям не выполнялись. HTTP-доступность не заменяет визуальную проверку и не подтверждает состояние рабочего D1. Инструмент web не смог открыть этот URL, проверка HTTP выполнена PowerShell `Invoke-WebRequest`.

Для портфолио: отдельное локальное демо с 5–8 вымышленными словами и функциями «перевернуть → ответить → увидеть прогресс → открыть словарь». Публичная ссылка должна называться «Открыть в Telegram» или пояснять необходимость Telegram. Не ставить обещание гостевого живого демо на исходный опубликованный URL.

### Ассеты и происхождение

Отдельных PNG/JPEG/WebP, видео, GLB и BLEND в проверенном EnCard checkout не найдено. Имеются SVG-иконки, шрифты встроены в HTML. Тексты лицензий Manrope и DM Serif Display (SIL OFL 1.1), а также IPA-данных `open-dict-data/ipa-dict` (MIT, dohliam) находятся в начале `index.html`. При копировании соответствующих ресурсов сохранить эти уведомления. В коде есть обращения к Wikimedia за произношением; для портфолио проще использовать беззвучную демонстрацию либо отдельный явно запрошенный запуск речи.

Общей лицензии кода в корне не найдено. Отдельные лицензионные файлы относятся к bundled shadcn-tailwind и Sites Vite plugin, а не ко всему проекту.

В репозитории присутствует `backups/wordflow.sqlite`, описанный README как снимок рабочей базы профилей. Содержимое базы не исследовалось. **Не включать эту базу, пользовательские словари, профили и `.openai` runtime-данные в ассеты портфолио или демо.** Копии `.research/` должны быть исключены из будущей публикации и production build.
